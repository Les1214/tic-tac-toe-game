# tic-tac-toe-game
This project is a Tic-Tac-Toe game developed as part of a team assignment. The goal was to create a fully functional game with proper game logic and user interaction.

Technologies Used
- Python
- GitHub for version control

My contributions 
- Helped implement game logic (turn handling and win conditions)
- Assisted with debugging and testing
- Collaborated with team members on GitHub

Features
- Two-player gameplay
- Option to play against another person or AI
- Input validation
- Win/draw detection

How to run
1. Download the files
2. Run the main program file
3. Follow prompts to play the game.
